Grupos de Botões do Bootstrap 5

Exemplos de como agrupar botões relacionados

1. Grupo de botões básico (.btn-group)

Use um elemento <div> com a classe .btn-group para criar um grupo de botões.

2. Tamanhos do grupo de botões

Em vez de aplicar o tamanho a cada botão do grupo individualmente, use a classe .btn-group-lg no próprio grupo para um grupo grande, ou .btn-group-sm para um grupo pequeno.



3. Grupos de botões verticais

O Bootstrap 5 também suporta grupos de botões verticais. Use a classe .btn-group-vertical para criar um grupo de botões vertical.

4. Barra de ferramentas (.btn-toolbar)

Vários grupos de botões podem ser combinados em uma barra de ferramentas usando a classe .btn-toolbar, útil para agrupar controles relacionados, como em um editor.

5. Grupo com dropdown

Um grupo de botões também pode conter um menu suspenso, combinando .btn-group com um botão .dropdown-toggle.
