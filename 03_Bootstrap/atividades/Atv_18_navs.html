Atividade 18

Navs

Enunciado

Com base no exemplo 18_navs.html, crie um sistema de abas funcional para a página de um produto.

  1. Crie uma navegação com .nav-tabs contendo três abas: "Descrição", "Avaliações" e "Perguntas".
  2. Para cada aba, crie um .tab-pane correspondente dentro de um .tab-content, com um texto diferente em cada um.
  3. Configure os atributos data-bs-toggle="tab" e data-bs-target para que clicar em uma aba realmente troque o conteúdo exibido (sem recarregar a página).
  4. Deixe a aba "Descrição" ativa por padrão ao carregar a página.
Dica: o id de cada .tab-pane precisa ser igual ao valor do data-bs-target do respectivo botão da aba. O JavaScript do Bootstrap já está incluído nesta página.
