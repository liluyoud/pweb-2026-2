Aula 07

TypeScript: tipos

O TypeScript é o JavaScript com tipos. Declaramos o que cada variável pode guardar e o compilador tsc encontra os erros antes de o código rodar. No final, o tsc gera JavaScript comum, que o Node.js ou o navegador executam.

  • TypeScript
  • tsc
  • Node.js
  • Tipos

O que está sendo visto

  • Compilação: o tsc transforma .ts em .js; o resultado roda no terminal com o Node.js (07a) ou em uma página HTML (07b).
  • Anotações e inferência: declarar o tipo explicitamente (let nome: string) ou deixar o TypeScript deduzir pelo valor.
  • Tipos primitivos: number, string e boolean.
  • Estruturas: tipos de objeto, arrays e tuplas.
  • Tipos especiais: any × unknown, void e never.
  • Combinações: enum, union types, tipos literais e type aliases.
  • Módulos: o export {}; no início de cada arquivo isola as variáveis, evitando conflito de nomes entre os exemplos.

Como executar

Com o Node.js instalado, instale o TypeScript uma vez e compile cada arquivo:

npm install -g typescript

cd 07a
tsc alo.ts          # gera alo.js
node alo.js         # executa no terminal

Para a página do 07b, compile o app.ts e abra o index.html no navegador. Na atividade, use tsc --strict para ligar a verificação mais rigorosa.
