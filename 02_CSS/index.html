Aula 02

CSS

O HTML diz o que é o conteúdo; o CSS diz como ele aparece. Nesta aula separamos a aparência em arquivos .css, vemos os principais seletores e montamos um portfólio completo com layout moderno.

  • CSS3
  • Seletores
  • Flexbox
  • Grid

O que está sendo visto

  • Separação de responsabilidades: a mesma página HTML ganha visuais completamente diferentes apenas trocando a folha de estilo (demo.html).
  • CSS externo: ligação com <link rel="stylesheet"> e uso de bibliotecas por CDN, como o Font Awesome para ícones.
  • Seletores: de tag (p), de atributo (p[newcolor]) e pseudo-classes de link (a:link, a:hover).
  • Layout moderno: variáveis CSS (:root e var()), Flexbox, Grid, transições, animações com @keyframes e responsividade com @media no portfólio.

Páginas da aula

  • Mesma página, estilos diferentes demo.html

    Um menu troca entre quatro folhas de estilo (ou nenhuma) com um pequeno script, mostrando que o HTML não muda.

  • Estilizando a página do exercício 02 page.html

    A página de produtos da aula 01 recebendo um CSS externo, seletores de atributo e estilos de link.

  • Portfólio portfolio.html

    Página completa com seções de apresentação, sobre, habilidades, projetos e contato, usando Flexbox, Grid e animações.
