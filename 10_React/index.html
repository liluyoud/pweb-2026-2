Aula 10

React

Uma pequena loja com três páginas, montada com React 19, Vite e React Router. O mesmo app aparece em três versões, em JavaScript, em TypeScript e com Bun, para comparar as ferramentas. Um tutorial interativo guia a construção da versão TypeScript passo a passo.

  • React 19
  • TypeScript
  • React Router
  • Vite
  • Bun

O que está sendo visto

  • Componentes e JSX: funções que retornam a interface, className, expressões entre chaves e componentes puros.
  • Props e children: passar dados e conteúdo para os componentes, com tipos, props opcionais e valores padrão.
  • Organização de pastas: componentes de UI genéricos (components/ui), componentes da aplicação (components), páginas (pages), dados (data) e tipos (types).
  • Listas: transformar um array em componentes com map e identificar cada item com key.
  • Rotas: BrowserRouter, Routes, Route, Link, NavLink e a rota * para a página não encontrada.
  • TypeScript no React: tipos para as props, ReactNode, import type e verificação de tipos no build com tsc.
  • Ferramentas: npm × Bun como gerenciador de pacotes, com o mesmo Vite como servidor e bundler.

Tutorial interativo

  • Protocolo React: construindo o ts-app tutorial/index.html

    10 aulas com fundamento teórico, código para copiar e uma pergunta sorteada que libera a próxima etapa. Ao final, o aluno recebe um certificado.

As três versões do app

As três versões têm as mesmas telas: Início, Produtos, Sobre e uma página para endereços inexistentes. O que muda é a linguagem e a ferramenta:

PastaLinguagemPacotesVerifica tipos?Diferenças
my-appJavaScript (.jsx)npmNãoTemplate react; props sem tipos.
ts-appTypeScript (.tsx)npmSim, no npm run buildTemplate react-ts; pasta types e props tipadas.
bun-appTypeScript (.tsx)BunSim, no bun run buildMesmo código do ts-app; bun.lock no lugar do package-lock.json.

Como executar

cd ts-app            # ou my-app
npm install
npm run dev          # abre em http://localhost:5173

cd bun-app
bun install
bun run dev

O index.html dentro de cada app é a página de entrada do Vite: aberto direto no navegador, ele fica em branco. Use o npm run dev (ou bun run dev) para ver a aplicação.
