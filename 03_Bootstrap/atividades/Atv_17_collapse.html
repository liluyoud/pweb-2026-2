Atividade 17

Collapse

Enunciado

Com base no exemplo 17_collapse.html, monte uma seção de perguntas frequentes (FAQ) para um site.

  1. Crie um .accordion com pelo menos 3 perguntas relacionadas a um tema de sua escolha (ex: uma loja, um curso, um aplicativo).
  2. Cada pergunta deve ser o cabeçalho de um item do accordion, e a resposta deve ficar dentro do corpo recolhível.
  3. Deixe apenas a primeira pergunta aberta por padrão (com a classe .show), as demais devem começar fechadas.
  4. Garanta que apenas uma pergunta fique aberta por vez, usando corretamente o data-bs-parent apontando para o accordion.
Dica: cada item precisa de um id único no botão (data-bs-target) e no .accordion-collapse correspondente.
