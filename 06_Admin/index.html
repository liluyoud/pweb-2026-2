Aula 06 · Projeto prático

Dashboard Admin com Blazor e MudBlazor

O projeto de maior peso da disciplina: a página Dashboard de um painel administrativo, com menu lateral, barra superior, indicadores, gráficos, listas e tabela. Todo o visual vem dos componentes e do tema do MudBlazor, sem nenhuma linha de CSS próprio.

  • Blazor WebAssembly
  • MudBlazor
  • Componentização
  • Gráficos

O que está sendo visto

  • Componentização: a página é montada com componentes pequenos e reutilizáveis, que recebem dados por [Parameter].
  • Componente base: o DashboardCard padroniza a moldura de todos os blocos (título, menu e conteúdo).
  • Tema: paleta clara e escura definida em um MudTheme, com alternância de modo escuro na barra superior.
  • Layout: menu lateral (MudDrawer) e barra superior com breadcrumb, busca, notificações e menu do usuário.
  • Gráficos: linha (receita × meta), rosca (distribuição de clientes) e mini gráficos de tendência nos KPIs, com MudChart.
  • Dados fictícios: todos os números vêm de records em C# na pasta Data, separados da interface.
  • Estilo sem CSS: espaçamento, cores e alinhamento só com propriedades dos componentes e classes utilitárias do MudBlazor.

Como executar

Com o .NET SDK 10 instalado, dentro desta pasta:

dotnet watch

A aplicação abre em http://localhost:5280 e é recompilada a cada arquivo salvo.
