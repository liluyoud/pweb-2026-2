Atividade 07

Imagens

Enunciado

Com base no exemplo 07_imagens.html, monte uma pequena galeria de fotos. Você pode usar imagens da internet, como as do serviço picsum.photos (ex: https://picsum.photos/id/1015/400/300).

  1. Adicione uma imagem grande de capa usando a classe .img-fluid, garantindo que ela se ajuste à largura do container.
  2. Crie uma galeria com pelo menos 4 imagens menores organizadas em um grid responsivo (.row + .col-6 .col-md-3), todas com .img-fluid .rounded.
  3. Adicione uma imagem de "avatar" circular usando .rounded-circle.
  4. Escolha uma das imagens da galeria e coloque uma legenda usando o componente <figure> / .figure-caption.
Dica: não esqueça de preencher o atributo alt de cada imagem descrevendo o conteúdo.
