Collapse do Bootstrap 5

Exemplos de conteúdo expansível e recolhível

1. Collapse básico

Um botão ou link com data-bs-toggle="collapse" apontando via href ou data-bs-target para o id do elemento com a classe .collapse controla sua exibição.

Este é um conteúdo que pode ser recolhido ou exibido com uma animação suave, sem sair da página.

2. Múltiplos alvos

Um mesmo controle pode abrir/fechar mais de um elemento ao mesmo tempo, informando vários seletores separados por vírgula em data-bs-target.

3. Collapse horizontal

Adicione a classe .collapse-horizontal para que o conteúdo se expanda na largura em vez da altura.

Conteúdo que se expande da esquerda para a direita, útil para painéis laterais.

4. Accordion

O componente .accordion agrupa vários itens de collapse, garantindo que apenas um fique aberto por vez (a menos que data-bs-parent seja removido).

É um framework CSS e JavaScript de código aberto para desenvolver sites e aplicações responsivas mais rapidamente.

Não é obrigatório: a maior parte dos componentes visuais funciona só com HTML e CSS. O JavaScript do Bootstrap é usado para comportamentos como este próprio accordion.

Sim, é totalmente gratuito e de código aberto, distribuído sob a licença MIT.

5. Accordion sem bordas (.accordion-flush)

A classe .accordion-flush remove bordas e cantos arredondados, deixando o accordion mais discreto, ideal para dentro de outros componentes.
