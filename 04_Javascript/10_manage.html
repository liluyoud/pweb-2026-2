JavaScript Event Management

Gerenciar eventos envolve adicionar, remover, bloquear e controlar como os eventos se comportam.

1. Adicionando eventos: addEventListener()

É possível adicionar vários listeners diferentes ao mesmo elemento, sem sobrescrever um ao outro.

2. Removendo eventos: removeEventListener()

O listener só pode ser removido se foi adicionado com uma função nomeada (não anônima).

Clique aqui (listener ativo)

3. Bloqueando eventos: preventDefault()

Impede o comportamento padrão do navegador para aquele evento.


Ir para w3schools.com

4. Controlando eventos: stopPropagation() (bubbling)

Por padrão, um clique num elemento filho também "borbulha" (bubbling) para os pais.
