Exercício: Listas em HTML (<ul>, <ol>, <dl>)

Complete os exercícios abaixo criando as listas solicitadas. Use o slide "Listas em HTML" como referência.

1. Lista não ordenada

Crie uma <ul> com os itens: "Arroz", "Feijão" e "Macarrão".

  • Arroz
  • Feijão
  • Macarrão

2. Lista ordenada

Crie uma <ol> com os passos: "Planejar", "Desenvolver", "Testar" e "Publicar".

  1. Planejar
  2. Desenvolver
  3. Testar
  4. Publicar

3. Lista de descrição

Crie uma <dl> relacionando os termos e suas descrições:

  • HTML — Linguagem de marcação para páginas web.
  • CSS — Usado para definir estilos e aparência.
HTML
Linguagem de marcação para páginas web.
CSS
Usado para definir estilos e aparência.

4. Lista com atributo type

Crie uma <ul type="circle"> com os itens "Item 1", "Item 2" e "Item 3".

  • Item 1
  • Item 2
  • Item 3

5. Lista ordenada com type e start

Crie uma <ol> que use letras maiúsculas (type="A") começando em "C" (start="3"), com os itens "Terceiro", "Quarto" e "Quinto". O resultado deve exibir "C. Terceiro", "D. Quarto", "E. Quinto".

  1. Terceiro
  2. Quarto
  3. Quinto

6. Lista ordenada invertida

Crie uma <ol reversed> com os itens "Primeiro", "Segundo" e "Terceiro", de forma que a numeração apareça invertida (3, 2, 1).

  1. Primeiro
  2. Segundo
  3. Terceiro

7. Listas aninhadas

Crie uma <ul> com dois itens principais, "Frutas" e "Verduras". Dentro de "Frutas", aninhe uma lista com "Maçã" e "Banana". Dentro de "Verduras", aninhe uma lista com "Alface" e "Espinafre".

  • Frutas
    • Maça
    • Banana
  • Verduras
    • Alface
    • Espinafre

Desafio extra

Abra este arquivo no navegador e confira se os marcadores, a numeração e as descrições estão exibidos corretamente. Depois, tente usar o atributo value em um <li> de uma lista ordenada para definir manualmente o número de um item.
