Exercício: A Tag <img>

Complete os exercícios abaixo usando a tag <img> e seus atributos. Use o slide "A Tag Image" como referência. Para as imagens, use o serviço https://picsum.photos/LARGURA/ALTURA, que gera imagens de exemplo (ex.: https://picsum.photos/600/338).

1. Imagem simples

Insira uma imagem com src e alt descrevendo "Paisagem de montanhas ao pôr do sol".

2. Imagem com largura e altura

Insira uma imagem com width="600" e height="338", com um alt apropriado.

3. Imagem com title

Insira uma imagem com o atributo title="Clique para ampliar", que deve aparecer como dica ao passar o mouse.

4. Carregamento otimizado

Insira uma imagem usando loading="lazy" e decoding="async" para otimizar o carregamento.

5. Imagem com class ou id

Insira uma imagem com id="banner", para que ela possa ser estilizada ou manipulada via CSS/JavaScript futuramente.

6. Imagem quebrada (teste do alt)

Insira uma imagem com um src inválido (ex.: "nao-existe.jpg") e um alt descritivo. Observe no navegador o que aparece no lugar da imagem quando ela não carrega.

Desafio extra

Abra este arquivo no navegador e responda:

  • O que aconteceu com a imagem do exercício 6? Por que o alt é tão importante?
  • A tag <img> precisa de uma tag de fechamento? Por quê?
  • Use as ferramentas de desenvolvedor (F12) para conferir se todos os atributos foram aplicados corretamente em cada imagem.
