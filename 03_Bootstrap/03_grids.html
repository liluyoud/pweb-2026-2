Sistema de Grid do Bootstrap 5

Exemplos de como organizar o conteúdo usando linhas (row) e colunas (col)

1. Colunas de largura igual

Quando não especificamos um número, o Bootstrap divide o espaço igualmente entre as colunas.

Coluna 1
Coluna 2
Coluna 3

2. Colunas com largura definida (base 12)

O grid do Bootstrap é dividido em 12 colunas. Podemos combinar tamanhos que somem 12.

col-4
col-4
col-4
col-8
col-4

3. Grid responsivo (breakpoints)

Redimensione a janela do navegador para ver as colunas se ajustando em telas pequenas, médias e grandes.

col-sm-6 col-md-4 col-lg-3
col-sm-6 col-md-4 col-lg-3
col-sm-6 col-md-4 col-lg-3
col-sm-6 col-md-4 col-lg-3

4. Deslocamento de colunas (offset)

A classe offset adiciona um espaço vazio antes da coluna.

col-4
col-4 offset-4

5. Colunas aninhadas (nesting)

É possível colocar uma nova linha (row) dentro de uma coluna para criar sub-colunas.

Coluna principal (col-8)
Sub-coluna 1
Sub-coluna 2
Coluna lateral (col-4)

6. Alinhamento e ordem das colunas

Use classes utilitárias como order e align-items-center para controlar o posicionamento.
