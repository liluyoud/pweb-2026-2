Exercício: Head da Página (Favicon, Title e Meta)

Complete o <head> deste documento seguindo as instruções abaixo. Use o slide "Head da Página" como referência.

Instruções

  1. Defina a codificação de caracteres do documento como UTF-8 usando a tag <meta charset>.
  2. Configure a tag <meta name="viewport"> para que a página seja responsiva em dispositivos móveis.
  3. Altere o <title> da página para: "Minha Loja - Produtos Artesanais"
  4. Adicione uma <meta name="description"> com o conteúdo: "Loja online de produtos artesanais feitos à mão."
  5. Adicione uma <meta name="keywords"> com pelo menos 3 palavras-chave relacionadas a uma loja de artesanato.
  6. Adicione uma <meta name="author"> com o seu nome.
  7. Adicione um favicon usando <link rel="icon"> apontando para um arquivo chamado favicon.png.
  8. Adicione uma <meta name="robots"> com o valor "index, follow".

Desafio extra

Abra este arquivo no navegador e verifique:

  • O título correto aparece na aba do navegador?
  • Se você tiver um arquivo de imagem PNG na mesma pasta, renomeie-o para favicon.png e veja se o ícone aparece na aba.
  • Use as ferramentas de desenvolvedor do navegador (F12) e inspecione o <head> para conferir se todas as tags foram adicionadas corretamente.
