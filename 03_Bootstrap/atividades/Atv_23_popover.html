Atividade 23

Popover

Enunciado

Com base no exemplo 23_popover.html, crie um botão de ajuda para um campo de formulário.

  1. Crie um campo de formulário para "Senha", com um ícone de ajuda (bi-info-circle) ao lado do rótulo.
  2. Configure um popover no ícone com título "Requisitos de senha" e um conteúdo explicando as regras (ex: mínimo de 8 caracteres, uma letra maiúscula e um número).
  3. Use data-bs-trigger="focus" para que o popover feche automaticamente ao clicar fora dele.
  4. No final da página, escreva o código JavaScript necessário para ativar o popover.
  5. Desafio extra: crie um segundo botão que mostra, em um popover com data-bs-html="true", uma pequena lista (<ul>) de recursos de um plano.
Dica: reveja o script no final do exemplo 23_popover.html — ele usa document.querySelectorAll('[data-bs-toggle="popover"]') e new bootstrap.Popover(...) para cada elemento encontrado.
