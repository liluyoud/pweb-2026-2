Aula 03

Bootstrap 5

Um framework CSS entrega classes prontas para layout e componentes. Em vez de escrever o CSS de cada botão ou grade, aplicamos classes como btn btn-primary e col-md-6. São 25 exemplos, do primeiro import ao modo escuro, cada um com uma atividade para praticar.

  • Bootstrap 5.3
  • Grid
  • Componentes
  • Responsividade

O que está sendo visto

  • Instalação via CDN: o CSS e o JavaScript do Bootstrap (5.3.8) são carregados direto da internet, sem instalar nada.
  • Layout: containers e o sistema de grid de 12 colunas, com pontos de quebra para cada tamanho de tela.
  • Conteúdo: tipografia, cores contextuais, tabelas e imagens responsivas.
  • Componentes: alertas, botões, badges, barras de progresso, cards, listas, menus, carrossel, modal e outros.
  • Componentes interativos: dropdown, collapse, modal, tooltip, popover e toast usam o JavaScript do Bootstrap, ativado por atributos data-bs-*.
  • Dark mode: troca de tema com o atributo data-bs-theme.

Cada atividade, na pasta atividades/, traz o enunciado no topo da página. Estude o exemplo e depois resolva a atividade correspondente.
