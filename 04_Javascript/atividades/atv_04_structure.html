Atividade 4: Manipulando a Estrutura do HTML

Complete as 3 funções abaixo para manipular a lista <ul id="lista">:

  1. adicionarItem(): use createElement() e appendChild() para criar um novo <li> com o texto "Novo item" e adicioná-lo ao final da lista.
  2. removerItem(): use removeChild() para remover o último item da lista (dica: lista.lastElementChild).
  3. substituirItem(): use replaceChild() para substituir o primeiro item da lista por um novo <li> com o texto "Item substituído".
