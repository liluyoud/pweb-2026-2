Botões do Bootstrap 5

Exemplos de estilos e classes utilitárias para botões

1. Cores de botões (.btn)

A classe .btn, combinada com uma classe contextual (.btn-primary, .btn-secondary, .btn-success, .btn-danger, .btn-warning, .btn-info, .btn-light e .btn-dark), estiliza o botão de acordo com o contexto.

2. Elementos que podem virar botões

A classe .btn pode ser aplicada a diferentes elementos HTML, e todos terão a mesma aparência de botão.

Link Button

3. Botões com borda (Outline)

O Bootstrap 5 também disponibiliza oito botões com apenas a borda colorida (.btn-outline-*), sem preenchimento de fundo.

4. Tamanhos de botões

Use a classe .btn-lg para botões grandes ou .btn-sm para botões pequenos.

5. Botões de largura total (Block Level)

Um botão de nível de bloco ocupa toda a largura do elemento pai. No Bootstrap 5, isso é feito colocando o botão dentro de um container com a classe .d-grid. A classe .d-grid cria um container em grid que faz o botão esticar por toda a largura disponível.

6. Botões ativos/desabilitados

Um botão pode ser definido como ativo (aparência pressionada) ou desabilitado (não clicável). A classe .active faz o botão parecer pressionado, e o atributo disabled torna o botão não clicável. Note que elementos <a> não suportam o atributo disabled e por isso devem usar a classe .disabled para parecerem desabilitados visualmente.

Link desabilitado

7. Botões com spinner

Também é possível adicionar "spinners" (indicadores de carregamento) a um botão, útil para mostrar que uma ação está em andamento.
