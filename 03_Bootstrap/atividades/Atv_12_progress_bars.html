Atividade 12

Barras de Progresso

Enunciado

Com base no exemplo 12_progress_bars.html, crie um painel que mostra o andamento de três projetos.

  1. Crie 3 barras de progresso, uma para cada projeto, com valores diferentes: 25%, 60% e 90%.
  2. Coloque um rótulo com a porcentagem dentro de cada barra.
  3. Use cores diferentes para cada projeto: .bg-danger para o projeto com menos progresso, .bg-warning para o intermediário e .bg-success para o mais avançado.
  4. Adicione a barra do projeto mais avançado com efeito listrado e animado (.progress-bar-striped .progress-bar-animated), simulando que ele está em andamento no momento.
Dica: não esqueça de manter os atributos aria-valuenow, aria-valuemin e aria-valuemax em cada barra.
