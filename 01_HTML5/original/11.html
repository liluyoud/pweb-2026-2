Exercício: Div e Span

Complete os exercícios abaixo usando <div> (elemento de bloco) e <span> (elemento inline). Use o slide "Div e Span" como referência.

1. Div como card

Crie uma <div class="card"> contendo um <h2> com o texto "Título da Seção" e um <p> com o texto "Este é um parágrafo dentro de uma div.".

2. Span para destacar texto

Complete o parágrafo abaixo, envolvendo a palavra "destaque" com <span class="destaque"> para poder estilizá-la depois.

Este é um texto em destaque dentro de um parágrafo.

3. Diferença entre bloco e inline

Crie duas <div> seguidas, cada uma com um texto curto dentro. Depois, crie dois <span> seguidos, cada um com um texto curto dentro. Observe no navegador a diferença: as divs devem quebrar linha automaticamente, enquanto os spans devem ficar um do lado do outro (se houver espaço).

4. Estruturando uma seção com div

Use <div> para agrupar um cabeçalho de página. Dentro da div, coloque um <h2> com "Cabeçalho do Site" e um <p> com "Menu de navegação aqui.".

5. Combinando div e span

Crie uma <div class="card"> com um parágrafo que contenha o texto "Status do pedido:" seguido de um <span class="destaque"> envolvendo a palavra "Entregue".
