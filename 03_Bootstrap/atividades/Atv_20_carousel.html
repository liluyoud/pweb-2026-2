Atividade 20

Carousel

Enunciado

Com base no exemplo 20_carousel.html, monte um carrossel de banners para a página inicial de uma loja. Você pode usar imagens de picsum.photos.

  1. Crie um carousel com pelo menos 3 slides de imagem.
  2. Adicione os controles de navegação (setas anterior/próximo).
  3. Adicione os indicadores (bolinhas) na parte inferior, permitindo pular direto para um slide.
  4. Coloque uma legenda (.carousel-caption) em cada slide com um pequeno título e uma frase de promoção.
  5. Desafio extra: aplique a classe .carousel-fade para que a transição entre os slides seja um efeito de dissolução em vez de deslizar.
Dica: o id do .carousel precisa ser referenciado em todos os botões de controle e indicadores através de data-bs-target.
