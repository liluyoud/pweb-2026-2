Atividade 25

Dark Mode

Enunciado

Com base no exemplo 25_darkmode.html, crie uma página com alternância de tema claro/escuro.

  1. Crie um botão "Alternar tema" no topo da página, com um ícone de lua/sol.
  2. Crie pelo menos um .card, uma tabela e um botão comum na página, para servirem de exemplo de como os componentes reagem à troca de tema.
  3. Escreva o código JavaScript que, ao clicar no botão, alterna o atributo data-bs-theme entre "light" e "dark" na tag <html>.
  4. Teste clicando algumas vezes no botão e observe os componentes mudando de aparência automaticamente, sem precisar trocar nenhuma classe deles.
  5. Desafio extra: salve a preferência do usuário no localStorage, como feito no exemplo, para que o tema escolhido seja lembrado ao recarregar a página.
Dica: use document.documentElement.setAttribute('data-bs-theme', 'dark') para ativar o modo escuro, e 'light' para o modo claro.
