Sistema de Grid

Enunciado

Usando o que foi visto em 03_grids.html, monte um "cartão de perfil" com o sistema de grid do Bootstrap (linhas e colunas somando 12).

  1. Crie uma .row com duas colunas:
    • Uma coluna menor (col-4) com fundo colorido representando uma "foto" (pode ser apenas um <div> com altura fixa e uma cor de fundo).
    • Uma coluna maior (col-8) com nome, profissão e uma breve descrição.
  2. Torne o layout responsivo: em telas pequenas as colunas devem ocupar a largura toda (empilhadas), e a partir do breakpoint md devem ficar lado a lado como no item anterior.
  3. Adicione uma segunda .row abaixo com 3 colunas de largura igual (sem número, apenas .col) contendo três habilidades ou informações extras.
Dica: para o item 2, use classes combinadas como col-12 col-md-4 e col-12 col-md-8.
