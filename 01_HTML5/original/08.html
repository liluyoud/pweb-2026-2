Exercício: Atributo Style

Use o atributo style para aplicar CSS diretamente nos elementos abaixo, seguindo cada instrução. Use o slide "Atributo Style" como referência.

1. Cor do texto

Deixe o parágrafo abaixo com a cor #CE0058.

Este texto deve ficar rosa/vermelho.

2. Cor de fundo

Deixe o parágrafo abaixo com fundo #FBD4DA.

Este texto deve ter um fundo rosa claro.

3. Tamanho e peso da fonte

Deixe o parágrafo abaixo com font-size: 18px e font-weight: bold.

Este texto deve ficar maior e em negrito.

4. Estilo itálico

Deixe o parágrafo abaixo em itálico usando font-style.

Este texto deve ficar em itálico.

5. Decoração e alinhamento

Sublinhe o parágrafo abaixo (text-decoration: underline) e centralize-o (text-align: center).

Este texto deve ficar sublinhado e centralizado.

6. Margem e espaçamento interno

Adicione margin: 10px e padding: 15px ao parágrafo abaixo.

Este texto deve ter espaço ao redor (margem) e espaço interno (padding).

7. Borda

Adicione uma borda 1px solid #CE0058 ao parágrafo abaixo.

Este texto deve ficar dentro de uma borda colorida.

8. Combinando tudo

Estilize o título e o link abaixo, reproduzindo o exemplo prático do slide:

  • O <h2> "Título Principal" deve ficar com color: #CE0058 e text-align: center.
  • O link "Saiba mais sobre a Afya" deve apontar para https://www.afya.com.br, ficar com color: #0057B7, text-decoration: none e font-weight: bold.
