Atividade 06

Tabelas

Enunciado

Com base no exemplo 06_tabelas.html, monte uma tabela de notas de uma turma.

  1. Crie uma tabela com as colunas: #, Nome, Nota e Situação.
  2. Adicione pelo menos 5 alunos com notas variadas (de 0 a 10).
  3. Aplique .table-striped e .table-hover na tabela.
  4. Na coluna "Situação", escreva "Aprovado" para notas maiores ou iguais a 6, e "Reprovado" para as demais.
  5. Use classes contextuais de linha para colorir cada aluno de acordo com a situação: .table-success para aprovados e .table-danger para reprovados.
Dica: a classe contextual vai no <tr> de cada aluno, não na tabela inteira.
