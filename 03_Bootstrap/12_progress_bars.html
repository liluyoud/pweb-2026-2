Barras de Progresso do Bootstrap 5

Exemplos de indicadores de progresso e carregamento

1. Barra de progresso básica

Envolva um elemento .progress-bar dentro de um .progress. A largura da barra é definida com o estilo width em porcentagem, e os atributos role="progressbar", aria-valuenow, aria-valuemin e aria-valuemax são usados para acessibilidade.

2. Altura da barra de progresso

A altura da barra de progresso é controlada pela propriedade height do container .progress, usando classes utilitárias como .style="height: Npx".

3. Rótulos na barra de progresso

Adicione um texto dentro de .progress-bar para mostrar um rótulo, como a porcentagem visível.

70%

4. Barras de progresso coloridas

Assim como outros componentes, as barras de progresso aceitam classes contextuais de cor: .bg-success, .bg-info, .bg-warning e .bg-danger.

5. Barras de progresso listradas

Adicione a classe .progress-bar-striped para dar um efeito de listras diagonais à barra de progresso.

6. Barra de progresso animada

Combine .progress-bar-striped com .progress-bar-animated para animar as listras da esquerda para a direita, dando a impressão de que a barra está em movimento.

7. Múltiplas barras de progresso

É possível colocar várias barras dentro do mesmo container .progress para representar diferentes partes de um todo.
