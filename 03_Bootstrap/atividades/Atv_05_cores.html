Atividade 05

Cores do Bootstrap

Enunciado

Com base no exemplo 05_cores.html, crie um painel de status de tarefas usando as classes contextuais de cor.

  1. Crie 4 blocos (podem ser <div> ou <p>) representando situações diferentes de tarefas:
    • "Concluída" — usando uma cor de sucesso;
    • "Atrasada" — usando uma cor de perigo;
    • "Em risco" — usando uma cor de aviso;
    • "Em análise" — usando uma cor informativa.
  2. Para cada bloco, use as classes .text-bg-* (que já ajustam a cor do texto automaticamente).
  3. Adicione um espaçamento interno (.p-2) e um espaçamento inferior (.mb-2) em cada bloco para ficarem bem separados.
Dica: classes contextuais disponíveis: primary, secondary, success, danger, warning, info, light e dark.
