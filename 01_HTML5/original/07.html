Exercício: Hyperlinks e Bookmarks

Complete os exercícios abaixo usando a tag <a> e seus atributos. Use o slide "Hyperlinks e Bookmarks" como referência.

1. Link para outra página do site

Crie um link com o texto "Ir para o exercício de Headings" que leve até o arquivo 03.html, nesta mesma pasta.

2. Link para todos os exercícios

Crie uma lista (<ul>) com um link para cada um dos arquivos desta pasta: 01.html, 02.html, 03.html, 04.html, 05.html e 06.html. Use um texto descritivo para cada link (não use "clique aqui").

3. Link para site externo

Crie um link para https://developer.mozilla.org com o texto "Documentação MDN". O link deve abrir em uma nova aba e usar rel="noopener" por segurança.

4. Link para e-mail

Crie um link com o texto "Enviar e-mail" que abra o cliente de e-mail do usuário para o endereço contato@afya.com.br.

5. Link para telefone

Crie um link com o texto "Ligar agora" que inicie uma ligação para o número +556999999999.

6. Link com atributo title

Crie um link para 05.html com o texto "Exercício de Listas" e adicione um title que exiba a dica "Clique para praticar ul, ol e dl" ao passar o mouse.

7. Bookmarks (âncoras internas)

Esta página já tem um <h1> com id="topo" no início. Crie um link aqui que leve até ele, com o texto "Voltar ao topo".

Agora marque o título abaixo com id="secao-final" e crie, nesta seção 7, um segundo link com o texto "Ir para a seção final" que leve até ele.

Seção final

Esta é a seção final da página. Marque o título "Seção final" acima com o id indicado no exercício 7.

Desafio extra

Abra este arquivo no navegador, clique em todos os links criados e confirme que cada um leva ao destino correto — incluindo os bookmarks, que devem rolar a página até o elemento certo.
