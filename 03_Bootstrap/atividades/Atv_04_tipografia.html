Atividade 04

Tipografia

Enunciado

Com base no exemplo 04_tipografia.html, monte um pequeno "post de blog" utilizando as classes de tipografia do Bootstrap.

  1. Crie um título de destaque para o post usando uma das classes .display-1 a .display-6.
  2. Abaixo, adicione um subtítulo usando <h4> com um trecho em <small class="text-muted"> indicando a data de publicação.
  3. Escreva pelo menos dois parágrafos de texto (pode ser Lorem Ipsum).
  4. Destaque uma palavra ou frase importante do texto usando <mark>.
  5. Finalize com uma citação usando a tag <blockquote> (procure a classe .blockquote na documentação do Bootstrap).
Dica: a documentação oficial de tipografia está em getbootstrap.com.
