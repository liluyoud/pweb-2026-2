Cores do Bootstrap 5

Exemplos de classes contextuais de cor para texto, fundo e a combinação dos dois

1. Cores de texto (.text-color)

O Bootstrap 5 possui classes contextuais que dão "significado através de cores". As classes de cor de texto são: .text-muted, .text-primary, .text-success, .text-info, .text-warning, .text-danger, .text-secondary, .text-white, .text-dark, .text-body e .text-light.

.text-muted

.text-primary

.text-success

.text-info

.text-warning

.text-danger

.text-secondary

.text-white (com fundo escuro para ficar visível)

.text-dark

.text-body (cor padrão do corpo do texto)

.text-light (com fundo escuro para ficar visível)

2. Cores de fundo (.bg-color)

As classes de cor de fundo são: .bg-primary, .bg-success, .bg-info, .bg-warning, .bg-danger, .bg-secondary, .bg-dark e .bg-light.

As classes .bg-color acima não funcionam muito bem com texto, ou pelo menos é preciso especificar uma classe .text-color adequada para obter a cor de texto correta em cada fundo.

.bg-primary

.bg-success

.bg-info

.bg-warning

.bg-danger

.bg-secondary

.bg-dark

.bg-light

3. Cores de fundo com texto automático (.text-bg-color)

Usando as classes .text-bg-color, o Bootstrap cuida automaticamente da cor de texto correta para cada cor de fundo, sem precisar combinar manualmente com uma classe .text-color.

.text-bg-primary

.text-bg-success

.text-bg-info

.text-bg-warning

.text-bg-danger

.text-bg-secondary

.text-bg-dark

.text-bg-light
