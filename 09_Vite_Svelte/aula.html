Aula 09

Vite e Svelte

O primeiro projeto criado com uma ferramenta de build. O Vite serve a aplicação durante o desenvolvimento e empacota tudo para publicação; o Svelte organiza a interface em componentes que juntam HTML, CSS e TypeScript em um único arquivo.

  • Vite 8
  • Svelte 5
  • TypeScript
  • Componentes

O que está sendo visto

  • Criação do projeto: npm create vite com o template Svelte + TypeScript, e a pasta node_modules criada pelo npm install.
  • Servidor de desenvolvimento: npm run dev abre a aplicação e atualiza a tela a cada arquivo salvo.
  • Componentes .svelte: um bloco <script lang="ts">, o HTML e um bloco <style> no mesmo arquivo.
  • Expressões no HTML: variáveis entre chaves, como {nome.toUpperCase()}, e atributos dinâmicos, como href={urlVite}.
  • Composição: o App importa e usa o componente <Aviso />.
  • CSS com escopo: o <style> de cada componente vale só para ele; o p do App e o do Aviso têm estilos diferentes.

Como executar

Este é um projeto Vite: o index.html desta pasta é a página de entrada da aplicação e só funciona pelo servidor do Vite. Dentro da pasta:

npm install      # baixa as dependências (só na primeira vez)
npm run dev      # abre em http://localhost:5173
npm run build    # gera a versão de produção na pasta dist
npm run check    # verifica os tipos dos componentes

Esta página de resumo se chama aula.html, e não index.html, porque o index.html desta pasta pertence ao Vite: trocá-lo quebraria a aplicação.

      • main.tsponto de entrada: monta o App na div#app com mount

    • node_modules/dependências instaladas pelo npm install (fora do Git)
