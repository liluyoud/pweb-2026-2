Tipografia do Bootstrap 5

Exemplos de títulos, textos de destaque e utilitários de texto

1. Font-size e line-height padrão

O Bootstrap 5 usa por padrão font-size: 1rem (16px) e line-height: 1.5. Além disso, todo elemento <p> já vem com margin-top: 0 e margin-bottom: 1rem (16px), sem precisar de classes extras.

2. Títulos (h1 a h6) e classes .h1 a .h6

Os elementos <h1> a <h6> já vêm estilizados pelo Bootstrap. As classes .h1 a .h6 aplicam o mesmo estilo em qualquer outra tag.

4. <small> ou .small

A tag <small> (ou a classe .small) deixa o texto menor e com cor mais suave, útil para textos secundários.

Este é um texto normal e este é um texto secundário com <small>.

5. <mark> ou .mark

A tag <mark> (ou a classe .mark) destaca um trecho de texto com fundo amarelo.

Use a tag mark para destacar um texto importante dentro do parágrafo.

É possível aplicar o mesmo efeito a outras tags usando a classe .mark.
