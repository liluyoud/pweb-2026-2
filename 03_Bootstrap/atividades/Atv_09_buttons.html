Atividade 09

Botões

Enunciado

Com base no exemplo 09_buttons.html, monte uma barra de ações para um painel administrativo.

  1. Crie um botão "Salvar" usando a cor success.
  2. Crie um botão "Cancelar" usando o estilo outline (.btn-outline-secondary).
  3. Crie um botão "Excluir" usando a cor danger, porém desabilitado (simulando que o usuário não tem permissão).
  4. Adicione um botão grande (.btn-lg) e um botão pequeno (.btn-sm) para comparar os tamanhos.
  5. Crie um botão de largura total usando .d-grid, simulando um botão de "Confirmar" em um formulário mobile.
Dica: para desabilitar um <button>, use o atributo disabled.
