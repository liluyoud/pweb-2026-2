Aula 08

TypeScript: estruturas e funções

Com os tipos dominados, vemos como o programa toma decisões, repete tarefas e se organiza em funções. Cada arquivo traz vários exemplos curtos, cada um dentro de um bloco { } para que as variáveis possam ser redeclaradas.

  • TypeScript
  • Decisão
  • Repetição
  • Funções

O que está sendo visto

  • Decisão: if/else, operadores lógicos, ternário e switch com cases agrupados.
  • Repetição: for e while, e o controle do laço com break e continue.
  • Funções tipadas: tipos dos parâmetros e do retorno, e o tipo de uma função como valor.
  • Parâmetros: opcionais (?), com valor padrão e rest (...).
  • Sobrecarga: várias assinaturas para a mesma função.
  • Do TypeScript para a página: na atividade, o código compilado é usado em uma página HTML e o projeto é publicado no GitHub.

Páginas da aula

  • Atividade: estruturas e funções z_atividade.html

    5 exercícios do mundo real, da situação do aluno ao caixa do mercado, com preparação do ambiente, depuração e entrega pelo GitHub.

Como executar os exemplos

tsc a_if_else.ts     # gera a_if_else.js
node a_if_else.js    # mostra os resultados no terminal
