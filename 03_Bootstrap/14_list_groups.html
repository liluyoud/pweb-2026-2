List Groups do Bootstrap 5

Exemplos de listas flexíveis para exibir séries de conteúdo

1. List Group básico

Use a classe .list-group em um <ul> e a classe .list-group-item em cada <li> para criar uma lista básica.

  • Primeiro item
  • Segundo item
  • Terceiro item
  • Quarto item

2. Estado ativo (.active)

Adicione a classe .active a um item para destacá-lo, indicando o item atualmente selecionado.

  • Primeiro item (ativo)
  • Segundo item
  • Terceiro item
  • Quarto item

3. Item desabilitado (.disabled)

Adicione a classe .disabled a um item para deixá-lo com aparência inativa.

  • Primeiro item
  • Segundo item (desabilitado)
  • Terceiro item

4. List Group com links ou botões

Em vez de <ul>/<li>, é possível usar <a> ou <button> para criar itens clicáveis, com efeito de hover automático. Para <a>, use .disabled em vez do atributo disabled.

Item ativo (link) Segundo item Terceiro item Item desabilitado

5. List Group sem bordas (.list-group-flush)

A classe .list-group-flush remove as bordas externas e os cantos arredondados, útil para colocar a lista dentro de outro componente, como um card.

  • Primeiro item
  • Segundo item
  • Terceiro item

6. Cores contextuais

Itens da lista podem receber classes contextuais de cor, como .list-group-item-success, .list-group-item-danger, entre outras.

  • Primary
  • Secondary
  • Success
  • Danger
  • Warning
  • Info
  • Light
  • Dark

7. List Group com badges

Combine itens de lista com .badge (usando d-flex para alinhar) para mostrar uma contagem ao lado do texto.

  • Caixa de entrada 12
  • Enviados 3
  • Lixeira 0

8. List Group horizontal

A classe .list-group-horizontal exibe os itens lado a lado em vez de empilhados.

  • Primeiro item
  • Segundo item
  • Terceiro item

9. Exemplo prático: menu de navegação

Combinando .list-group, ícones (Bootstrap Icons), .active, .disabled e .badge, é possível montar um menu de navegação como o de um aplicativo, com item ativo destacado, contador de notificações e item desabilitado.
