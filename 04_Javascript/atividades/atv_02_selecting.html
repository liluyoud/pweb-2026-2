Atividade 2: Métodos de Seleção

Complete cada função usando o método de seleção indicado:

  1. testarId(): use getElementById() para selecionar o parágrafo com id "unico" e mudar sua cor para azul.
  2. testarTag(): use getElementsByTagName("li") para colocar todos os itens da lista em negrito.
  3. testarClasse(): use getElementsByClassName("destaque") para colocar fundo amarelo em todos os elementos com essa classe.
  4. testarQuery(): use querySelector(".destaque") para sublinhar apenas o PRIMEIRO elemento com classe "destaque".
  5. testarQueryAll(): use querySelectorAll(".destaque") para colocar borda vermelha em TODOS os elementos com essa classe.
