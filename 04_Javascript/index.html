Aula 04

JavaScript: DOM e eventos

Com JavaScript a página deixa de ser estática. O navegador transforma o HTML em uma árvore de objetos, o DOM, que o JavaScript pode ler e modificar, e avisa o código sempre que algo acontece, por meio de eventos.

  • JavaScript
  • DOM
  • Eventos
  • Formulários

O que está sendo visto

  • O que é o DOM: a árvore de objetos que o navegador monta a partir do HTML.
  • Seleção: getElementById, getElementsByClassName, getElementsByTagName, querySelector e querySelectorAll.
  • Alteração: textContent × innerHTML, atributos com setAttribute e estilos com element.style.
  • Estrutura: criar, adicionar, remover e substituir elementos (createElement, appendChild, removeChild, replaceChild).
  • Eventos: handlers por propriedade e com addEventListener; eventos de mouse, teclado e carregamento (DOMContentLoaded × load).
  • Formulários: validação com atributos HTML, pseudo-seletores CSS e checkValidity().

O material de apoio completo, com explicações e exemplos comentados de cada tema, está no README.md. As regras da atividade avaliativa estão em atividades/atividade.md. Os arquivos .md são exibidos como texto simples no navegador; no GitHub ou no VS Code eles aparecem formatados.
