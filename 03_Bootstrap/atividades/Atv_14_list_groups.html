Atividade 14

List Groups

Enunciado

Com base no exemplo 14_list_groups.html (incluindo o menu de navegação com ícones visto em aula), monte o menu lateral de um aplicativo de finanças pessoais.

  1. Crie um .list-group com pelo menos 4 itens: "Início", "Transações", "Cartões" e "Ajustes".
  2. Adicione um ícone (do Bootstrap Icons, já importado nesta página) na frente de cada item.
  3. Marque o item "Início" como .active.
  4. No item "Transações", adicione um .badge à direita mostrando a quantidade de transações pendentes (ex: 7).
  5. Deixe o item "Cartões" com aparência .disabled, simulando uma funcionalidade ainda não disponível para o usuário.
Dica: use .d-flex .align-items-center .gap-2 em cada item para alinhar bem o ícone com o texto.
