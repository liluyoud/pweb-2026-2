Atividade 22

Tooltip

Enunciado

Com base no exemplo 22_tooltip.html, crie uma pequena barra de ferramentas de ícones com dicas explicativas.

  1. Crie 3 botões de ícone (use os ícones do Bootstrap Icons, já importados nesta página), por exemplo: "Editar" (bi-pencil), "Compartilhar" (bi-share) e "Excluir" (bi-trash).
  2. Adicione um tooltip a cada botão, usando o atributo title com o nome da ação.
  3. Configure posições diferentes para pelo menos dois tooltips, usando data-bs-placement (ex: um em cima e outro embaixo).
  4. No final da página, escreva o código JavaScript necessário para ativar todos os tooltips (lembre-se: eles não funcionam sozinhos, precisam ser inicializados).
Dica: reveja o script no final do exemplo 22_tooltip.html — ele usa document.querySelectorAll('[data-bs-toggle="tooltip"]') e new bootstrap.Tooltip(...) para cada elemento encontrado.
