Tooltips do Bootstrap 5

Exemplos de dicas contextuais ao passar o mouse

1. Tooltip básico

Adicione data-bs-toggle="tooltip" e o texto no atributo title a qualquer elemento. Diferente de outros componentes, tooltips precisam ser ativados via JavaScript (veja o script no final da página).

2. Direções (.data-bs-placement)

O atributo data-bs-placement controla onde o tooltip aparece: top, right, bottom ou left.

3. Tooltip em links de texto

Tooltips também funcionam bem em links dentro de um parágrafo, como uma explicação rápida para um termo, por exemplo API ou CSS.

4. Tooltip com HTML

Com data-bs-html="true" é possível incluir HTML dentro do conteúdo do tooltip, como texto em negrito ou quebras de linha.

5. Tooltip customizado (cor)

É possível personalizar a aparência do tooltip com CSS, sobrescrevendo variáveis do Bootstrap como --bs-tooltip-bg em uma classe própria.

6. Tooltips em ícones

Um uso muito comum é adicionar tooltips a botões de ícone, esclarecendo sua função sem precisar de texto visível.

7. Exemplo prático: formulário com dicas de ajuda

Ícones de ajuda () com tooltip são muito usados em formulários para explicar campos sem poluir a interface.
