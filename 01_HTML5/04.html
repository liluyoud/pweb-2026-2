Exercício: Tags Essenciais para Texto (<p>, <br>, <hr>)

Use as tags <p>, <br> e <hr> para organizar o conteúdo abaixo, que hoje está tudo em texto corrido.

Instruções

  1. Separe o texto "Bem-vindo ao meu blog" em um parágrafo próprio, usando a tag <p>.
  2. No endereço de contato, use <br> para quebrar as linhas "Rua das Flores, 123", "Bairro Centro" e "Cidade - Estado" dentro de um único parágrafo, sem criar espaço extra entre elas.
  3. Adicione uma <hr> para separar o bloco de "Sobre o autor" do bloco de "Últimas notícias", já que são conteúdos tematicamente diferentes.
  4. Transforme as três notícias em parágrafos separados, cada uma com sua própria tag <p>.
  5. Não use <br> para separar parágrafos inteiros — isso deve ser feito com <p>. Use <br> apenas para quebras de linha pontuais dentro de um mesmo bloco.
