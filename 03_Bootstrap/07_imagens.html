Imagens do Bootstrap 5

Exemplos de classes utilitárias para tratar imagens

1. Imagem responsiva (.img-fluid)

A classe .img-fluid aplica max-width: 100% e height: auto à imagem, fazendo com que ela se ajuste ao tamanho do elemento pai (útil para telas de todos os tamanhos).

2. Miniaturas (.img-thumbnail)

A classe .img-thumbnail adiciona uma borda arredondada e um leve espaçamento ao redor da imagem, como se fosse uma moldura.

3. Formas de imagem

O Bootstrap possui classes utilitárias para dar formas diferentes às imagens: .rounded (cantos arredondados), .rounded-circle (círculo) e .shadow (sombra).

4. Alinhamento de imagens

Imagens podem ser alinhadas com classes de float, com .mx-auto junto de .d-block (centralizar) ou com classes de texto como .text-center.

5. Componente Figure

O componente <figure> combina uma imagem (.figure-img) com uma legenda (.figure-caption), útil para mostrar imagens com uma descrição.

6. Galeria responsiva

Combinando o sistema de grid com .img-fluid é possível montar uma galeria de imagens que se adapta ao tamanho da tela.
