Dark Mode do Bootstrap 5

Exemplos de temas claro/escuro nativos do Bootstrap 5.3+

1. Como funciona

Desde a versão 5.3, o Bootstrap suporta temas nativamente através do atributo data-bs-theme="dark" (ou "light"). Ele pode ser aplicado na tag <html> para trocar o tema da página inteira, ou em qualquer elemento específico para aplicar o tema apenas àquela seção.

2. Alternador de tema funcional

O botão abaixo alterna data-bs-theme na tag <html> via JavaScript e salva a escolha no localStorage, para lembrar a preferência na próxima visita. Clique para ver toda a página mudar de tema.

3. Componentes se adaptam automaticamente

Botões, cards, tabelas, formulários e a maioria dos componentes do Bootstrap já usam variáveis de cor que respondem ao tema — sem precisar trocar nenhuma classe. Altere o tema acima e veja os elementos abaixo mudarem.

4. Tema aplicado apenas a uma seção

É possível fixar um tema específico em um elemento com data-bs-theme, ignorando o tema global da página — útil para uma barra lateral, um rodapé ou um card que devem sempre aparecer escuros (ou claros), independente da preferência do usuário.
