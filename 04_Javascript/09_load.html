JavaScript Load Events

DOMContentLoaded x window load

DOMContentLoaded dispara assim que o HTML foi totalmente lido e a árvore DOM está pronta, sem esperar imagens, folhas de estilo, etc. Já o load da window só dispara depois que TODOS os recursos dependentes da página (imagens, CSS, scripts, sub-frames) terminaram de carregar.

Observe no log abaixo qual evento dispara primeiro.
